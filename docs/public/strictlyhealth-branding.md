# StrictlyHealth identity

The app display name and launch identity are StrictlyHealth. The original SH monogram uses white lettering with a teal intersection on charcoal; it is not third-party brand artwork.

The app icon is an opaque 1024 × 1024 square. iOS supplies its Home Screen mask. The launch view uses the same full-color asset, avoiding differences between separate redraws.

Assets:

- `apps/ios/OuraApp/Assets.xcassets/AppIcon.appiconset/icon-1024.png`
- `apps/ios/OuraApp/Assets.xcassets/StrictlyHealthMark.imageset/strictlyhealth-mark.png`

Created with the built-in image-generation tool, resized mechanically to 1024 pixels. The exact prompt is embedded in each PNG's metadata. No generated text beyond SH is used; the app name is native text.

## Generation prompt

+ Use case: logo-brand
 Asset type: production iOS app icon and matching launch logo for StrictlyHealth, an independent Oura ring and Apple Health dashboard.
 Primary request: original, beautifully balanced SH monogram. A bold flowing S interlocks cleanly with a strong H through shared geometric strokes. Both letters are unmistakable at small sizes. Athletic, precise, warm modern health identity; not a medical cross or an ECG clipart mark.
 Scene/backdrop: completely flat very dark charcoal square background, edge to edge, fully opaque.
 Style/medium: crisp vector-like flat graphic design, master icon artwork, sharp clean curves, no texture.
 Composition/framing: square 1024 x 1024 canvas, one optically centered monogram occupying about 62 percent of width and height, generous consistent margin. Draw no outer rounded square; iOS applies its own mask.
 Color palette: soft white for the main monogram, one restrained saturated teal stroke segment integrated into the S/H intersection, reflecting the existing app's teal navigation.
 Text: only the stylized letters "SH". No brand wordmark in the image.
 Constraints: original identity, simple scalable silhouette, no thin details, no gradients, no glow, no shadows, no concentric circles, no rings, no heartbeat line, no medical cross, no border, no mockup, no watermark. Exact full-bleed opaque square icon, not a sheet of options.

Changing the display identity does not change the bundle identifier, stored measurements or pairing keys.
